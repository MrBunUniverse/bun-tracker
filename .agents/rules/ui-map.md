# UI Map Navigation

For visual UI requests, consult `docs/dev/UI_MAP.md` before searching. It lists files and symbols, not line numbers: open the listed file and `rg` the symbol. The map is a fast index, not a substitute for reading the code. For look and feel, follow `docs/dev/DESIGN.md`.

Update `docs/dev/UI_MAP.md` when a component moves, is renamed, or changes responsibility. Keep entries to one line each and never add line ranges.
